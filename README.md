# Rock Paper Scissors

A simple **Rock Paper Scissors** game project built while learning and practicing JavaScript fundamentals.

The project demonstrates how JavaScript can be used to create interactive web experiences, handle user input, update the DOM, and implement game logic.

## About the Project

This repository contains a collection of JavaScript exercises and different stages of a Rock Paper Scissors game. The project was developed progressively to practice JavaScript concepts and understand how they can be applied to a real interactive game.

The repository includes different versions of the game as new JavaScript concepts were introduced.

## Features

* Rock Paper Scissors gameplay
* Player vs computer game logic
* Random computer choices
* Score tracking
* Interactive buttons
* DOM manipulation
* JavaScript functions
* Objects and variables
* Arrays and loops
* Advanced JavaScript functions
* Different versions showing the development process

## Technologies Used

* HTML5
* CSS3
* JavaScript

## How to Run

1. Clone the repository:

```bash
git clone https://github.com/Prayush-Shrestha/rock-paper-scissors.git
```

2. Open the project folder.

3. Open one of the Rock Paper Scissors HTML files in your web browser.

For example:

```text
12-rock-paper-scissors.html
```

4. Choose Rock, Paper, or Scissors and play against the computer.

## Game Rules

* Rock beats Scissors
* Scissors beats Paper
* Paper beats Rock
* The same choice results in a draw

## Learning Objectives

This project was created to practice and understand:

* JavaScript variables and data types
* Boolean values and conditional statements
* Functions
* Objects
* Arrays
* Loops
* DOM manipulation
* Event handling
* Random number generation
